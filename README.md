# daily fitness · Demo 0.4

[简体中文](README.md) · [English](README.en.md) · [下载 / Download](https://github.com/losslesswow-tech/dailyfitness/releases/latest) · [建议与问题 / Feedback](https://github.com/losslesswow-tech/dailyfitness/issues/new/choose)

可离线试用的健身日历，支持 Android 安装和电脑浏览器预览。Demo 采用本地 HTML/CSS/JavaScript 界面与 Java Android 安装壳；完整产品规划中的 Kotlin / Compose / Room 原生版尚未实现。

欢迎大家下载试用，并通过 [GitHub Issues](https://github.com/losslesswow-tech/dailyfitness/issues/new/choose) 分享更新建议、使用体验和问题反馈，中英文均可。提出建议时，可以告诉我你想完成什么、现在遇到什么困难，以及希望怎样改善；请勿公开上传个人健康备份或签名密钥。

**0.4 新增：** 页面顶部的“语言 / Language”支持简体中文和 English，首次按系统语言选择，可随时切换并自动记住。内置运动、器械、餐次和动作提供英文名称；自定义文字和历史记录保持原样，食物保留官方原始名称。GitHub 提供双语介绍与反馈模板；应用“我的 / Profile”也有建议入口，通过外部浏览器打开。

应用名称统一为 **daily fitness**。图标将两个“日”字作为左右杠铃片，中横连接为杠铃杆，沿用深绿与浅绿配色。[SVG 图标](web/icon.svg) 为矢量源文件；[PNG 预览](docs/images/daily-fitness-icon.png) 为 512 × 512 透明圆角版本。Android 桌面使用同款自适应图标，支持系统的圆形和圆角遮罩。

## 开始试用

安装文件：[dailyfitness-demo-0.4.apk](https://github.com/losslesswow-tech/dailyfitness/releases/download/v0.4.0/dailyfitness-demo-0.4.apk)。本地构建输出位于 `artifacts/`，GitHub 安装包统一存放在 Releases。同包名、同签名，版本号递增，可在 Demo 0.1 / 0.2 / 0.3 上覆盖更新，数据格式保持兼容。更新前仍建议导出一份备份，无需卸载旧版。

1. 将 APK 通过 USB、Quick Share 或你常用的文件传输方式发到三星 S24。
2. 在手机“我的文件”中打开 APK，按系统提示允许该来源安装，然后安装“daily fitness”。无需打开开发者模式或 USB 调试。
3. 首次打开可填写身体资料，也可以先体验界面。初始不含虚构健康记录。
4. 从日历添加运动、饮食、睡眠；在“训练”中建立分化计划或快速开始三大项。页面顶部可切换中文 / English。

若三星的安全设置阻止安装，先查看手机提示并判断是否允许这次本地测试安装；Demo 不会自动修改系统安全设置。手机组织管理策略可能禁止侧载，需要使用你有权使用的设备。

最低 Android 8.0 / API 26，目标 API 35。APK 使用本地 Demo 签名，仅供侧载试用，不是商店正式发行包。未在真实 S24 上安装验证。

## 已实现

- 日历默认今天，支持切月、选日期及回到今天；所选日期下显示当日报告。
- 有氧：全部初始项目、时长、距离与自动速度换算，以及坡度、爬升、楼层、台阶、跳绳个数等专项字段；可自定义仅记录时长的项目。
- 跑步、骑行、散步、爬坡等填总时间后，距离或速度任选一项，自动补算另一项；爬坡另记坡度，未手动填齐距离和速度不会阻止保存。
- 距离单位可选米 / 千米；速度可选 km/h、分钟/公里、小时/公里，切换单位保留物理量，保存时统一为 km 与 km/h。
- 游泳支持自由泳、蛙泳、蝶泳、仰泳；25/50/75/100 m 泳池，单程趟数和总时间。自动距离 = 泳池长度 × 单程趟数，一个来回是两趟；旧版按距离录入的游泳记录仍可编辑。
- 有氧指标改为平铺的两列，单位放在输入框内，左右标题与输入框对齐。
- 力量：三至六分化计划，每个训练日一个部位；按训练日开始并轮转，可手动选择。
- 中性人体部位示意图与文字选择；三大项快速入口、动作搜索、自定义动作和器械选择。
- 每组重量与次数、热身标记、动作备注、单组修正、动作历史；次数手动填写，重量自动继承同动作和器械的最近记录。
- 完成动作后继续下一动作；整场结束后写入日历。未结束训练自动保存，可关闭后恢复。
- 前台组间 90 秒休息倒计时，可关闭、重计或跳过。
- 哑铃默认总重量，不自动乘 2；杠铃输入两侧片重，另加当次杆重，默认 20 kg。
- 饮食六类餐次、默认当前时间且可修改、多次练后餐自动命名、4/4/9 热量换算。
- 饮食新增“按食物名称估算”：选择具体食物、填写可食用重量、支持一餐多项汇总；保存 USDA 来源、FDC 编号、数据版本和每 100 g 数值快照，历史记录不会随食物库更新改变。
- 跨夜睡眠归到起床当天，记录起夜；每个起床日期一条主要睡眠。
- 身体测量历史、成年人基础代谢估算展示范围。
- 体重、腰围、臂围、体脂、有氧时长、力量组数与容量、饮食和睡眠趋势；7/30/90/365 天。
- 日常记录编辑删除、JSON 备份导出与恢复，导入先验证再替换。
- “我的 → 清空全部数据”：输入“清空”后执行，可先导出备份；删除全部个人记录、计划、自定义项目和草稿，保留内置食物库和已导出的文件。保存失败不会假装清空成功。
- 运动消耗估算：有氧按运动类型、时长、当日可用体重与 MET 估算；力量训练结束时确认整场时长和强度，多动作只计一次，也可从日历补填旧场次时长。
- 当日报告和趋势新增“运动额外消耗”，排除同期静息部分；详情可看总消耗及来源。采用 19–59 岁成人模型，缺资料或不支持的条件显示未估算，不用 0 冒充。

## 数据说明

Android 记录写入应用私有文件，使用 AtomicFile 提交；语言偏好单独保存，没有网络权限。来源和反馈链接通过系统外部浏览器打开，不会自动上传记录；提交 GitHub 建议需要网络和 GitHub 账号。导出和导入通过系统文件选择器完成，不申请全盘存储权限。浏览器预览的数据只存在该浏览器，不会自动同步到手机。清空应用内记录和恢复健康备份不会改变语言选择。

卸载、清除应用数据或清除浏览器存储会删除相应记录。请在“我的 → 导出备份”保存 JSON；Android 与浏览器可通过此备份手动互相转移。恢复备份会替换当前数据，导入前会确认。当前最多接受 4 MB 备份。

基础代谢按 Mifflin–St Jeor 成人公式估算，显示公式值上下 10% 范围，仅作展示参照，不等同全天总消耗、实测区间或摄入建议。睡眠显示手动输入的起止时段，未猜测并扣除起夜时间。力量容量为外部总重 × 次数求和，包含热身组，不含身体自重。

食物库包含两类官方来源：原有 [USDA FoodData Central](https://fdc.nal.usda.gov/download-datasets/) 8,157 项，新增[卫福部食品药物管理署食品营养成分资料集](https://data.gov.tw/dataset/8543) 2,159 项中文食品，共 10,316 项。中文食品包括馒头、熟水饺、叉烧肉、广东粥、油条等中式 / 台式食品，也有食材和加工食品；保留冷冻、熟制等原始状态说明，不能代表所有地区菜谱或特定餐厅。支持按中文食品 / USDA 范围筛选。缺数据或无匹配项时不会编造估算值。数据来源、转换、许可和限制见 [食物数据说明](docs/食物数据说明.md)。

按食物估算时，热量使用数据库能量值；手动改变营养素后切换为 4/4/9 计算，界面明确提示。添加食物不会静默覆盖已有手动输入，可通过“用食物合计填写”替换。食物名称本身无法确定份量，请用可食部分的克数，并核对生熟状态；包装食品优先使用包装标签。

运动消耗采用[2024 Adult Compendium](https://pacompendium.com/adult-compendium/) 的原始 MET 数值。主显示为扣除 1 MET 同期静息消耗后的额外消耗；不能直接当成全天总消耗或建议摄入量。计算方法、适用范围和历史记录处理见 [运动消耗估算说明](docs/运动消耗估算说明.md)。

## Demo 的边界

- 分化计划当前保存训练日与部位，未实现预先编排动作模板和目标组；开始当天训练后添加动作。
- 尚无计划复制 / 动作拖拽排序、自定义图表日期范围、按具体动作或器械筛选图表。
- 人体为可点击的简化示意图，尚非完整前后视图肌肉插画。
- 杆重按每个杠铃动作设置，尚无全局杆重设置页；哑铃口径固定为用户指定的总重。
- 当前训练结束前，只能在“运动中”修改当前动作的组；已完成动作可在整场结束后从日历修正。
- 没有后台通知、云同步、实时联网食物查询、穿戴设备连接或自动加重建议。
- 未做 S24 真机、系统软键盘、Samsung Internet WebView 版本或手机文件选择器的实际验证。

## 在电脑运行

安装 Node.js 后在本目录执行：

```powershell
npm install
npm start
```

打开 http://127.0.0.1:4173 。服务仅监听本机，不对局域网开放。

## 重新构建 APK

本项目提供不依赖 Gradle 的最小 Demo 构建脚本。工具放在 `.tools/`，不修改系统 Java 安装，也不写入系统 Android SDK 目录。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/setup-android.ps1
npm run build:android
```

首次工具安装需要联网，下载约 310 MB。SDK 来自 Google 官方源并核对索引校验和，JDK 来自 Microsoft 官方下载源。工具自身的许可证保留在下载目录，使用时遵循对应条款。

构建使用 `.local/signing/demo.keystore`，请保留该文件，以便后续安装同签名的 Demo 更新。它是开发测试签名，不能作为正式发布密钥。更换签名或改为正式版时，先导出备份再迁移数据。
