# 分享建议 / Share feedback

欢迎通过 [GitHub Issues](https://github.com/losslesswow-tech/dailyfitness/issues/new/choose) 分享功能建议和问题，中文、English 均可。感谢每一条能帮助 daily fitness 变得更好用的反馈。

Suggestions and bug reports are welcome in English or Chinese through [GitHub Issues](https://github.com/losslesswow-tech/dailyfitness/issues/new/choose). Your feedback helps shape future updates.

- **功能建议 / Feature ideas：** 你想完成什么、当前哪里不方便、希望怎样改善。Describe your goal, the current difficulty and the change you would like.
- **问题反馈 / Bug reports：** 应用版本、手机型号与系统、界面语言、重现步骤、预期与实际结果。Include the app version, device/OS, UI language, steps, expected behavior and what happened.
- 请勿公开上传个人健康备份、可识别身份的信息或签名密钥；截图请先遮挡私人内容。Do not post personal health backups, identifying information or signing keys; redact screenshots first.
- 反馈是自愿的，安装使用不要求你提交建议。Feedback is optional; using the app does not require submitting it.

代码改动请说明解决的问题和验证方式。界面文案集中在 `web/i18n.js`，内置记录的存储值保持兼容；运行 `npm test` 和 `npm run test:ui` 检查两种语言。

For code changes, describe the problem and validation. UI messages live in `web/i18n.js`; preserve stored values for backward compatibility. Run `npm test` and `npm run test:ui` to check both languages.
