## 本次更新

- “我的 → 清空全部数据”：查看删除范围，可先导出备份；必须输入“清空”才能执行，取消不会删除。保留内置食物库和已导出的文件，保存失败时保留原数据。
- 有氧记录增加运动消耗估算；日历展示扣除同期静息部分后的额外消耗，详情保留总消耗、计算口径和来源。
- 力量训练结束时确认整场时长及强度，同场多个动作只计一次；旧场次可在日历动作详情补填。
- 趋势新增“运动额外消耗”。
- 新增食药署官方中文食品 2,159 项，合计食物库 10,316 项，支持中文食品 / USDA 范围筛选；保留来源、样品状态及营养值快照。

运动消耗参照 2024 Adult Compendium，当前模型适用 19–59 岁；缺体重、时长或不支持的活动不估算。额外运动消耗不等于全天总消耗，也不是建议摄入量。

中文食品来自卫福部食品药物管理署 2026《食品营养成分资料集》，依政府资料开放授权条款第1版使用。食品包含熟制、冷冻等不同状态，请核对说明。
