## 功能与试用

离线健身日历初版，支持身体资料、有氧、饮食、跨夜睡眠、分化训练、逐组力量记录、趋势与 JSON 备份。应用名称为 daily fitness，图标采用两个“日”字组成的杠铃。

将 APK 发到手机，在“我的文件”中打开，按系统提示允许本次安装来源后安装。无需 USB 调试。

1. 填身体资料，进入日历，添加一次 30 分钟、5 km 的跑步，观察自动速度。
2. 添加饮食：蛋白质 30 g、碳水 60 g、脂肪 10 g，显示 450 kcal；可添加多次练后餐。
3. 新建三分化，选择胸、背、腿；开始训练，记录动作与每组重量、次数，完成动作后继续下一动作，最后结束整场训练。
4. 未结束训练时退出并重新打开，从“继续训练”恢复。
5. 记录跨夜睡眠，查看当日报告和趋势，再从“我的”导出 JSON 备份。

哑铃按总重填写；杠铃填写两侧片重，另加当次杆重，默认 20 kg。数据保存在本机，卸载或清除数据前先备份。

本版为 Web 界面加 Java Android 安装壳的 Demo，尚无预编排动作模板、后台提醒或健康设备同步；未进行三星 S24 真机验证。APK 为开发测试签名侧载包。
