# daily fitness Demo 0.4 · 中文 / English

## 中文

daily fitness 现在公开提供下载试用，欢迎大家通过 [GitHub Issues](https://github.com/losslesswow-tech/dailyfitness/issues/new/choose) 分享更新建议、使用体验和问题，中英文均可。反馈是自愿的，提交前请遮挡个人信息，不要上传健康备份或签名密钥。

### 本次更新

- 软件顶部新增“语言 / Language”，可选择简体中文或 English。首次跟随系统语言，之后记住你的选择；Android 和浏览器均支持。
- 日历、训练、趋势、身体资料、饮食、睡眠、校验错误及计算说明均提供英文；内置运动、器械、餐次和动作按语言显示。
- 切换语言保留当前页面未提交的输入，不更改历史数据、计划、自定义名称、备注或营养快照。旧版 JSON 备份保持兼容。
- 英文界面优先显示 USDA 英文原名；食药署食品保留官方中文原名和来源。
- “我的 / Profile”新增建议入口，通过外部浏览器打开 GitHub。仓库提供中英文介绍和功能建议 / 问题反馈模板。
- 清空操作按语言确认：中文输入“清空”，英文输入 `CLEAR`；清空记录或恢复备份保留语言偏好。

35 项逻辑测试和 32 项浏览器界面测试通过；已查看英文手机界面，并检查 360 / 393 / 1280 px 布局。APK v2 / v3 签名通过，12 个 Web 资源与源码逐字节一致。未做三星 S24 真机、系统软键盘或系统文件选择器验证。

## English

daily fitness is now publicly available to try. **Help shape the next update** by sharing ideas, use cases and bug reports through [GitHub Issues](https://github.com/losslesswow-tech/dailyfitness/issues/new/choose), in English or Chinese. Feedback is optional. Please redact private information and never upload health backups or signing keys.

### What's new

- A **语言 / Language** selector on every screen for **简体中文** and **English**. The first launch follows your system language; your choice is remembered on Android and in the browser.
- Localized calendar, training, trends, profile, meals, sleep, validation and calculation notes, including built-in activities, equipment, meal types and exercises.
- Switching preserves unsaved inputs on the current screen and does not rewrite history, plans, custom names, notes or nutrition snapshots. Existing JSON backups remain compatible.
- USDA foods prioritize their original English descriptions in English mode. TFDA foods retain their official Chinese names and provenance.
- In-app feedback links open GitHub in your external browser. The repository includes English/Chinese introductions and feature-request / bug-report templates.
- Clearing records requires typing `CLEAR` in English or `清空` in Chinese. Clearing or restoring records keeps your language preference.

### Install and validation

Download the attached `dailyfitness-demo-0.4.apk`. Package: `cn.dailyfitness.demo`; version: `0.4.0-demo`; versionCode: `5`; Android 8.0 / API 26+, target API 35. The signing certificate matches versions 0.1–0.3, so you can update without uninstalling. Export a backup first.

35 logic tests and 32 browser tests passed. English mobile screens were visually reviewed, with layout checks at 360 / 393 / 1280 px. APK v2/v3 signatures were verified and all 12 packaged Web assets match the source byte for byte. Physical Samsung S24 installation, its keyboard and system file pickers remain untested.

This is a development-signed offline demo, not a store release. Health records stay on the device; feedback/source links use your external browser and do not automatically upload records. Submitting feedback requires internet access and a GitHub account.
